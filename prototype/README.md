# Prototipe hero (HTML)

HTML + CSS + JavaScript biasa, tanpa build tool. Diorama 3D dibuat prosedural dengan three.js (`vendor/`), font disimpan sendiri di `fonts/`.

Cara melihat di laptop (PowerShell):

```
cd D:\taxi-sintang\prototype
python -m http.server 8080
```

Lalu buka http://localhost:8080 di browser. File harus dibuka lewat server, bukan dengan klik dua kali, karena modul JavaScript tidak jalan dari `file://`.

Belum ada: video Dreamina (`media/hero-kabut-kapuas-*.mp4`) dan model mobil Meshy. Jarak dan waktu tempuh masih perkiraan.
